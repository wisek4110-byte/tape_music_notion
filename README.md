# 🎞️ Cassette Tape Player — Notion 임베드 위젯

노션 페이지에 붙여 넣을 수 있는 **카세트 테이프 모양 음악 플레이어**입니다.
유튜브 영상이나 재생목록을 넣으면, 재생할 때 가운데 릴(휠)이 진짜 테이프처럼 돌아갑니다.

서버가 필요 없는 정적 파일입니다. `index.html` 과 `assets/` 폴더(그림 4장)를 **함께** 올려야 합니다.

```
index.html
assets/
├─ cassette.png   카세트 배경 (975×627)
├─ wheel.png      릴(휠) 121×121, 재생 중 회전
├─ repeat.png     반복 아이콘 (흰색, 투명 배경)
└─ settings.png   설정 톱니바퀴 (흰색, 투명 배경)
```

---

## 1. 배포하기 (GitHub Pages)

1. 이 저장소 → **Settings → Pages**
2. *Source* 를 **Deploy from a branch**, 브랜치는 이 브랜치(또는 `main`), 폴더는 `/ (root)` 로 지정 후 저장
3. 1~2분 뒤 아래 주소가 열립니다

```
https://<깃허브아이디>.github.io/tape_music_notion/
```

> 다른 정적 호스팅(Netlify, Vercel, Cloudflare Pages)에 올려도 똑같이 동작합니다. 이때도 `assets/` 폴더를 빼먹지 마세요.

---

## 2. 내 음악으로 설정하기

1. 위 주소를 브라우저에서 엽니다.
2. 카세트 위에 마우스를 올리면 오른쪽 위에 **⚙ 설정** 버튼이 나타납니다(평소에는 완전히 투명). 누르세요.
   *(터치 화면에서는 카세트를 한 번 탭하면 3초 동안 나타납니다. ▶ 를 곡이 없는 상태로 눌러도 설정창이 열립니다.)*
3. 항목을 채웁니다.
   - **테이프 제목** — 최대 20자. 카세트 라벨에 들어갑니다.
   - **재생 전 문구** — 기본값 `pon play para empezar` (재생을 시작하면 현재 곡 제목으로 자동으로 바뀝니다)
   - **글씨체** — 손글씨(필기체) / 타자기 / 고딕
   - **기본 반복** — 전체 반복(기본) / 한 곡 반복
   - **음악 목록** — 유튜브 주소를 그대로 붙여넣기 (영상·재생목록 모두 가능). `+ 칸 추가`로 **최대 20개**까지, `✕`로 삭제
4. **[임베드 주소 복사]** 를 누릅니다. (설정이 담긴 주소가 복사됩니다)
5. 노션에서 `/임베드` (또는 `/embed`) 블록을 만들고 복사한 주소를 붙여넣기 → **Embed link**
6. 블록 모서리를 끌어 크기를 조절하세요. 가로 400~600px 정도가 보기 좋습니다.

> 설정은 **주소(URL) 안에** 저장됩니다. 그래서 노션에는 반드시 *복사한 임베드 주소*를 넣어야 하고,
> 나중에 곡을 바꾸려면 노션 블록의 주소만 새 주소로 교체하면 됩니다.
>
> 주소에 설정이 들어 있으므로 **창을 닫았다 열어도, 시크릿 모드로 열어도, 다른 기기·다른 사람이 열어도** 그대로 재생됩니다.
> 반대로 `적용`만 누르고 주소를 복사해 두지 않으면 그 브라우저에만 임시로 남습니다(시크릿 모드에서는 창을 닫는 순간 사라집니다).

### 붙여넣을 수 있는 주소 형식

| 형식 | 예시 | 인식 |
|---|---|---|
| 일반 영상 | `https://www.youtube.com/watch?v=XXXXXXXXXXX` | 영상 1곡 |
| 단축 주소 | `https://youtu.be/XXXXXXXXXXX` | 영상 1곡 |
| Shorts | `https://www.youtube.com/shorts/XXXXXXXXXXX` | 영상 1곡 |
| 재생목록 | `https://www.youtube.com/playlist?list=PL...` | 재생목록 전체 |
| 재생목록 안의 영상 | `...watch?v=XXX&list=PL...` | 재생목록 전체 *(설정창의 `이 영상 한 곡만` 버튼으로 한 곡만 지정 가능)* |

재생목록은 **한 칸에 목록 전체**가 들어갑니다. 예를 들어 1번 칸에 재생목록, 2·3번 칸에 단일 영상을 넣으면
재생목록을 끝까지 들은 뒤 2번, 3번 곡으로 이어집니다. 칸은 최대 20개까지 쓸 수 있습니다.

## 3. 조작 방법

| 버튼 | 동작 |
|---|---|
| ⏮ (왼쪽 원) | 이전 곡 (3초 이상 재생 중이면 처음으로 되감기) |
| ▶ / ⏸ (붉은 원) | 재생 / 일시정지 — 재생 중에는 양쪽 릴이 회전합니다 |
| ⏭ (오른쪽 원) | 다음 곡 (재생목록 안에서는 목록의 다음 곡) |
| 파형 막대 | 흰색이 지나온 구간, 회색이 남은 구간. 클릭·드래그로 원하는 위치로 이동 (키보드 ←/→ 5초 이동) |
| 🔁 (오른쪽 끝) | 반복 모드 전환 — **전체 반복(기본)**: 화살표만 / **한 곡 반복**: 화살표에 `1` 배지 |

- 스페이스바로도 재생/일시정지가 됩니다.
- 테이프 제목은 라벨의 **첫 번째 줄 위에** 얹혀 쓰이고, 길면 라벨 폭을 넘지 않도록 글자 크기가 자동으로 줄어듭니다.
- 아래 파란 회색 띠에는 **현재 재생 중인 유튜브 영상 제목**이 표시됩니다. 폭은 고정이고, 길면 좌우로 천천히 흐릅니다. 옆의 음표(♪)는 움직이지 않습니다. (재생 전에는 설정한 "재생 전 문구")
- 노션 임베드 블록의 크기를 바꿔도 카세트는 비율을 유지한 채 블록 안에 맞게 줄어들고, 배경은 투명이라 노션 페이지 색에 그대로 어울립니다.

## 4. 주소 파라미터 (직접 편집용)

설정창을 쓰지 않고 주소를 직접 만들 수도 있습니다.

```
index.html?t=Love%20Songs&s=pon%20play%20para%20empezar&f=hand&r=all&a=p:PLxxxx,v:dQw4w9WgXcQ
```

| 파라미터 | 뜻 | 값 |
|---|---|---|
| `t` | 테이프 제목 | 문자열(20자 이내 권장) |
| `s` | 재생 전 문구 | 문자열 |
| `f` | 글씨체 | `hand`(손글씨) · `type`(타자기) · `sans`(고딕) |
| `r` | 기본 반복 모드 | `all`(전체) · `one`(한 곡) |
| `a` | 트랙 목록(최대 20개) | `v:영상ID` / `p:재생목록ID` 를 쉼표로 이어 붙임 (예: `a=v:AAA,p:PLBBB`) |

> 이전 버전의 `a1`,`a2`,`a3` 형식도 그대로 인식합니다.

## 5. 알아두면 좋은 점

- 유튜브 **IFrame Player API**로 재생합니다. 영상 화면은 숨겨져 있고 소리만 나옵니다.
- 업로더가 **외부 사이트 재생(퍼가기)을 막아둔 영상**은 재생되지 않습니다. 이때는 "이 영상은 재생할 수 없어요" 문구가 뜨고 다음 곡으로 넘어갑니다.
- 브라우저 정책상 **첫 재생은 ▶ 버튼을 직접 눌러야** 시작됩니다(자동재생 불가).
- 노션 **모바일 앱**은 임베드 안의 소리 재생이 제한될 수 있습니다. PC 브라우저 / 노션 데스크톱 앱에서 가장 잘 동작합니다.
- 글씨체는 Google Fonts(Caveat · 나눔펜 · Special Elite)를 사용하며, 네트워크가 막힌 환경에서는 시스템 글꼴로 자동 대체됩니다.

## 6. 그림 바꾸기

`assets/` 의 그림을 같은 크기·같은 자리 구성으로 바꿔 끼우면 디자인이 바뀝니다.

- `cassette.png` — 975×627. 휠이 놓이는 자리는 왼쪽 (221, 216), 오른쪽 (635, 216) 이고 이 자리에는 휠을 그리지 마세요(검은 창만).
  라벨의 두 줄(y=121, 152), 아래 파란 회색 띠(y=386~435)도 이 그림 안에 들어 있습니다.
- `wheel.png` — 121×121, 가운데와 바깥이 투명한 PNG.
- `repeat.png`, `settings.png` — 흰색 글리프 + 투명 배경 PNG (정사각형).
- 버튼·글자·파형 위치는 `index.html` 의 CSS 에 **원본 그림의 픽셀 좌표 그대로**(`calc(216*var(--u))` 처럼) 적혀 있어, 그림을 다른 배치로 바꾸면 그 숫자만 고치면 됩니다.

## 7. 파형 모양 바꾸기

아래 진행바의 막대는 `index.html` 안의 `WAVE` 목록 **한 줄**로 그려집니다.

```js
var WAVE=[76,42,66,73,87,63,40,33,49,80,77,38,60,38,92,65,87,99,89,83,65,53,81,59,34,99,100,75,44,54];
```

- 숫자는 막대 높이(%)입니다. 100이 둥근 버튼과 같은 높이이고, 개수는 자유입니다(같은 간격으로 퍼집니다).
- 막대 굵기는 바로 아래 `drawWave` 안의 `BW`(기본 4.2)로 조절합니다. 막대 수를 늘리면 `BW` 를 줄여야 간격이 유지됩니다.
- 모든 막대는 가운데선을 기준으로 위아래 대칭이고 끝이 둥글며, 재생된 만큼은 크림색, 남은 부분은 회색으로 칠해집니다.

## 8. 노션에서 재생이 안 될 때

단독 페이지에서는 되는데 노션 임베드에서만 안 되는 것은 **구조가 달라서**입니다. 노션 안에서는 `노션 페이지 → 이 위젯(iframe) → 유튜브 재생기(iframe)` 로 한 겹이 더 생기고, 이때 노션이 어떤 권한을 주느냐에 따라 아래 중 하나가 막힐 수 있습니다.

| 원인 | 증상 |
|---|---|
| 노션의 iframe 이 **자동 재생 권한(`autoplay`)을 넘겨주지 않음** | ▶ 를 눌러도 아무 일도 안 일어남(에러 없음) |
| 유튜브가 **출처(Referer)** 를 못 받음 (오류 **153**) | 재생기 설정 오류 |
| 임베드가 **저장소/스크립트를 제한**(샌드박스) | 플레이어가 응답하지 않음 |

위젯은 이를 스스로 처리합니다.

- ▶ 를 눌러도 약 4초 안에 재생이 시작되지 않으면 **실제 유튜브 플레이어 패널**이 카세트 위에 나타나며 이유를 적어 줍니다.
  패널 안의 ▶ 를 **한 번만** 누르면(그 클릭이 유튜브 화면 안에서 일어나야 자동 재생이 허용됩니다) 패널이 사라지고 그 뒤로는 평소처럼 동작합니다.
- 오류 **153** 이면 자동으로 `youtube-nocookie.com` 주소로 한 번 더 시도하고, 그래도 안 되면 원인을 알려 줍니다.
- 곡이 모두 재생 불가(소유자가 퍼가기를 막음 등)면 계속 건너뛰지 않고 멈춰서 알려 줍니다.
- 패널의 **새 창에서 열기 ↗** 로 단독 페이지를 열 수 있습니다.
- 패널 맨 아래 작은 회색 줄은 진단 정보(임베드 여부·임베드한 사이트·origin·저장소 상태·플레이어 상태·오류 코드)입니다. 문의할 때 그 줄이 보이게 캡처해 주세요.
