# 🎞️ Cassette Tape Player — Notion 임베드 위젯

노션 페이지에 붙여 넣을 수 있는 **카세트 테이프 모양 음악 플레이어**입니다.
유튜브 영상이나 재생목록을 넣으면, 재생할 때 가운데 릴(휠)이 진짜 테이프처럼 돌아갑니다.

파일은 `index.html` 하나뿐이고 서버가 필요 없습니다.

---

## 1. 배포하기 (GitHub Pages)

1. 이 저장소 → **Settings → Pages**
2. *Source* 를 **Deploy from a branch**, 브랜치는 이 브랜치(또는 `main`), 폴더는 `/ (root)` 로 지정 후 저장
3. 1~2분 뒤 아래 주소가 열립니다

```
https://<깃허브아이디>.github.io/tape_music_notion/
```

> 다른 정적 호스팅(Netlify, Vercel, Cloudflare Pages)에 `index.html` 을 올려도 똑같이 동작합니다.

---

## 2. 내 음악으로 설정하기

1. 위 주소를 브라우저에서 엽니다.
2. 카세트 오른쪽 위의 **⚙ 설정** 버튼을 누릅니다.
3. 항목을 채웁니다.
   - **테이프 제목** — 최대 20자. 카세트 라벨에 들어갑니다.
   - **재생 전 문구** — 기본값 `pon play para empezar` (재생을 시작하면 현재 곡 제목으로 자동으로 바뀝니다)
   - **글씨체** — 손글씨(필기체) / 타자기 / 고딕
   - **기본 반복** — 전체 반복(기본) / 한 곡 반복
   - **음악 목록** — 유튜브 주소를 그대로 붙여넣기 (영상·재생목록 모두 가능). `+ 칸 추가`로 **최대 20개**까지, `✕`로 삭제
4. **[임베드 주소 복사]** 를 누릅니다. (설정이 담긴 주소가 복사됩니다)
5. 노션에서 `/임베드` (또는 `/embed`) 블록을 만들고 복사한 주소를 붙여넣기 → **Embed link**
6. 블록 모서리를 끌어 크기를 조절하세요. 가로 400~600px 정도가 보기 좋습니다.

> 설정은 **주소(URL) 안에** 저장됩니다. 그래서 노션에는 반드시 *복사한 임베드 주소*를 넣어야 하고,
> 나중에 곡을 바꾸려면 노션 블록의 주소만 새 주소로 교체하면 됩니다.
>
> 주소에 설정이 들어 있으므로 **창을 닫았다 열어도, 시크릿 모드로 열어도, 다른 기기·다른 사람이 열어도** 그대로 재생됩니다.
> 반대로 `적용`만 누르고 주소를 복사해 두지 않으면 그 브라우저에만 임시로 남습니다(시크릿 모드에서는 창을 닫는 순간 사라집니다).

### 붙여넣을 수 있는 주소 형식

| 형식 | 예시 | 인식 |
|---|---|---|
| 일반 영상 | `https://www.youtube.com/watch?v=XXXXXXXXXXX` | 영상 1곡 |
| 단축 주소 | `https://youtu.be/XXXXXXXXXXX` | 영상 1곡 |
| Shorts | `https://www.youtube.com/shorts/XXXXXXXXXXX` | 영상 1곡 |
| 재생목록 | `https://www.youtube.com/playlist?list=PL...` | 재생목록 전체 |
| 재생목록 안의 영상 | `...watch?v=XXX&list=PL...` | 재생목록 전체 *(설정창의 `이 영상 한 곡만` 버튼으로 한 곡만 지정 가능)* |

재생목록은 **한 칸에 목록 전체**가 들어갑니다. 예를 들어 1번 칸에 재생목록, 2·3번 칸에 단일 영상을 넣으면
재생목록을 끝까지 들은 뒤 2번, 3번 곡으로 이어집니다. 칸은 최대 20개까지 쓸 수 있습니다.

## 3. 조작 방법

| 버튼 | 동작 |
|---|---|
| ⏮ | 이전 곡 (3초 이상 재생 중이면 처음으로 되감기) |
| ▶ / ⏸ | 재생 / 일시정지 — 재생 중에는 양쪽 릴이 회전합니다 |
| ⏭ | 다음 곡 (재생목록 안에서는 목록의 다음 곡) |
| 진행바 | 드래그하거나 클릭해서 원하는 위치로 이동 (키보드 ←/→ 5초 이동) |
| 🔁 | 반복 모드 전환 — **전체 반복(기본)** ↔ **한 곡 반복(1 표시)** |

- 스페이스바로도 재생/일시정지가 됩니다.
- 왼쪽 `A` 배지는 곡이 2개 이상일 때 현재 트랙 번호(`A1` … `A20`)를 보여줍니다.
- 오른쪽 `60` 자리는 재생 중 **테이프 카운터**(현재 재생 시간)로 바뀝니다.
- 테이프 제목이 길면 카세트 폭을 넘지 않도록 글자 크기가 자동으로 줄어듭니다.
- 릴 아래 문구 자리에는 **현재 재생 중인 유튜브 영상 제목**이 표시되고, 길면 좌우로 천천히 흐릅니다. 옆의 음표(♪)는 고정입니다.
- 재생이 진행될수록 왼쪽 릴에 감긴 테이프가 줄고 오른쪽 릴로 감깁니다(실제 카세트와 같은 방식).

## 4. 주소 파라미터 (직접 편집용)

설정창을 쓰지 않고 주소를 직접 만들 수도 있습니다.

```
index.html?t=Love%20Songs&s=pon%20play%20para%20empezar&f=hand&r=all&a=p:PLxxxx,v:dQw4w9WgXcQ
```

| 파라미터 | 뜻 | 값 |
|---|---|---|
| `t` | 테이프 제목 | 문자열(20자 이내 권장) |
| `s` | 아래 문구 | 문자열 |
| `f` | 글씨체 | `hand`(손글씨) · `type`(타자기) · `sans`(고딕) |
| `r` | 기본 반복 모드 | `all`(전체) · `one`(한 곡) |
| `a` | 트랙 목록(최대 20개) | `v:영상ID` / `p:재생목록ID` 를 쉼표로 이어 붙임 (예: `a=v:AAA,p:PLBBB`) |

> 이전 버전의 `a1`,`a2`,`a3` 형식도 그대로 인식합니다.

## 5. 알아두면 좋은 점

- 유튜브 **IFrame Player API**로 재생합니다. 영상 화면은 숨겨져 있고 소리만 나옵니다.
- 업로더가 **외부 사이트 재생(퍼가기)을 막아둔 영상**은 재생되지 않습니다. 이때는 "이 영상은 재생할 수 없어요" 문구가 뜨고 다음 곡으로 넘어갑니다.
- 브라우저 정책상 **첫 재생은 ▶ 버튼을 직접 눌러야** 시작됩니다(자동재생 불가).
- 노션 **모바일 앱**은 임베드 안의 소리 재생이 제한될 수 있습니다. PC 브라우저 / 노션 데스크톱 앱에서 가장 잘 동작합니다.
- 글씨체는 Google Fonts(Caveat · 나눔펜 · Special Elite)를 사용하며, 네트워크가 막힌 환경에서는 시스템 글꼴로 자동 대체됩니다.
